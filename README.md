# HR_Analytics_Payroll_Analysis
Analyzed employee data, payroll distribution, and workforce trends using SQL, Python, and Excel. Identified salary discrepancies, compensation patterns, and HR-related insights. Developed an interactive dashboard and evaluated potential improvements through salary adjustment scenarios and an A/B testing plan.
# Tools:
SQL, Python (Pandas), Google Sheets.
# My tasks:
- Data cleaning and preparation, documenting data quality issues and cleaning rules
- Analyzing payroll, employee distribution, and HR metrics using SQL
- Identifying salary outliers, gender pay gap, and employees earning below the average for their positions
- Analyzing hiring trends and payroll distribution across departments and cities
- Developing Excel dashboards, salary increase scenarios, and payroll impact calculations
- Designing an A/B test to evaluate an employee onboarding improveme
# Result:
Created an HR analytics solution combining SQL analysis and Excel dashboards. Identified key workforce and compensation trends, evaluated salary adjustment scenarios, and developed data-driven recommendations to support HR decision-making. Prepared an A/B testing plan to assess the effectiveness of onboarding improvements.
